= Fork Features & Improvements

This fork includes significant enhancements and new features over the upstream repository.

== New Game Systems

=== Gacha System
* Full Box Gacha implementation with buy, draw, list, and reset functionality
* Standard Gacha support with configurable prize pools
* Persistent gacha state and pull history tracking

=== GP (Game Points) Shop
* Complete GP Shop with purchase and browsing capabilities
* GP Course management (activation, validation, available courses)
* CAP to GP conversion system
* Purchase history tracking

=== Pawn Expedition System
* Full expedition (sally) system implementation
* Expedition rewards and drop collection
* Golden sally support for premium expeditions
* Sally count charging and cancellation

=== Mandragora Crafting
* Mandragora crafting system with finish/check mechanics
* Golden craft support for premium crafting
* Item retrieval from completed crafts

=== Quick Party System
* Party matching and registration
* Quest-based party registration
* Party ready notifications

=== Equipment Presets
* Save and load equipment preset configurations
* Preset naming and management

=== Mail System
* Personal mail send, receive, and delete functionality
* Mail text retrieval
* Send notifications

=== Reward Mission System (リワードミッション)
* Full daily mission system with 6 mission types: login, gather items, defeat enemies, clear quests, craft items, pawn expeditions
* Milestone rewards for completing multiple missions (3, 5, 8 missions)
* 5 AM JST daily reset with automatic progress tracking
* Configurable mission definitions and rewards via JSON assets

=== Large Delivery Events (大口納品イベント / Infinity Delivery)
* Solo-friendly material delivery system (no competitive rankings)
* Deliver items to NPCs (Seneka) at White Dragon Temple to earn points
* Point thresholds (borders) unlock rewards: Gold, Rift Points, Blood Orbs, items
* Weekly reset on Monday 5 AM JST
* Configurable categories, items, point values, and border rewards

=== Additional Features
* Event code redemption system
* NPC Bazaar sell functionality
* Official/Legend pawn support
* Free rental pawn listings
* Item storage info queries
* Blacklist management
* Friend recent character list
* Group chat member list
